# Support

mythical-skills is maintained on a best-effort basis.

- **Questions and problems with skill content** — open a GitHub issue using
  the templates in `.github/ISSUE_TEMPLATE/`.
- **Proposals for new skills** — open a "Skill proposal" issue first;
  `CONTRIBUTING.md` describes the authoring expectations before you write.
- **Security concerns** — never a public issue; see `SECURITY.md` and mail
  **dev@mythicalos.ai**.
- **Anything else** — dev@mythicalos.ai.

Note that this repository carries content only. Problems with how a consuming
deployment links, namespaces, or authorizes skills belong to that deployment's
own tooling, not here.
